# Habblaud para VS Code

Extensão companion oficial para visualizar seus agentes do **Claude Code** e **Codex** diretamente dentro do VS Code.

## Como Usar

1. Inicie o servidor do Habblaud no repositório:
   ```bash
   npm run dev
   ```
2. Abra o ícone do **Habblaud** na Barra de Atividades (Activity Bar) do VS Code.
3. Para abrir em tela cheia / nova aba:
   - Use o ícone de expandir no topo da visualização; ou
   - Pressione `Ctrl+Shift+P` (ou `Cmd+Shift+P`) e digite: `Habblaud: Abrir em Nova Aba`.

## Configurações

- `habblaud.serverUrl`: Altere caso o Habblaud esteja rodando em outra porta (padrão: `http://127.0.0.1:4747`).
